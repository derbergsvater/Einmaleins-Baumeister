# 1x1 Baumeister

> Rechne richtig — bau dein Ding!

Webapp (mobile first) für Grundschüler: Das kleine Einmaleins (1er- bis 10er-Reihe)
wird trainiert, indem jede richtige Antwort sichtbar an einem Wunschobjekt
weiterbaut — Rennwagen, Zauberschloss und mehr. Wer die Meisterprüfung einer
Zahlenreihe besteht, schaltet Addons frei (Heckflügel, Turbo, … bis zum
fliegenden Auto).

- **Konzept:** [KONZEPT.md](KONZEPT.md)
- **Stack:** Vanilla JS, SVG, localStorage, GitHub Pages — kein Backend
- **Status:** Konzeptphase
